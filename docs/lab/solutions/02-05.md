# Solutions — Labs 02–05

## Lab 02

**2-A header table** (all three files identical structure):

| Field | f000… file | 0025d751… | 0122fd93… |
|---|---|---|---|
| version | 17 | 17 | 17 |
| data offset | 0x1000 | 0x1000 | 0x1000 |
| endianness | LE | LE | LE |
| version string | 2018.2.16f1 | same | same |
| platform | 13 (Android) | same | same |

Version strings are 4-byte aligned so the reader can memcpy word-at-a-time.

**2-B** starter provided (`exercises/02-B.py` is left as the exercise; the
checker accepts any 10 files passing).

**2-C** the legacy size field is from SerializedFile v<7 layout; v17 stores
the true size in the container's external info, not the file header. Formats
evolve by *accretion* — old fields survive as vestiges.

**2-D** offset/size pairs are position-independent (the blob can live
anywhere in memory, mmap'd read-only) and make each section independently
skippable — a linked list would force sequential reads and pointer patching.

## Lab 04

**4-A** determinism: metadata parsing is pure pointer/offset arithmetic over
immutable bytes — no timestamps, no randomness, no dict-ordering dependence in
the C# tool's output. Reproducibility matters when *another person* must
verify your evidence (science, audits, patching).

**4-B** type_index.json: 12,414 types; 8,012 global. Reasons: (1) era style —
Korean mobile studios frequently skipped namespaces; (2) Unity's default
Assembly-CSharp encourages flat layout; (3) obfuscation tooling of the era
flattened names anyway.

**4-C** URL filter yields the endpoint set in ARCHITECTURE §4 — game hosts on
`*.nexon.com:9080`, AWS dev EC2s, Akamai CDNs, S3 QA buckets, notice/terms
pages, and the socket.io URL template.

**4-D** O(1) exact-match by address: a dict (hash map) keyed by the 64-bit
address; binary search fails because queries hit *interior* addresses
(function bodies), and a sorted array can't answer "which entry owns this
range?" in O(1) without interval trees — hence hashing exact starts +
Ghidra's own function-range index for interior hits.

## Lab 05

**5-A** export report: 3,615 assets, ~6 min, 0 failed, 512 MB
(`analysis/export_report.md`).

**5-B** 18 scenes exported; scene YAML objects reference assets via
`{fileID, guid, type}`; the GUID resolves to the sibling `.meta` file —
Unity's reference graph is human-readable YAML, AssetRipper preserved it.

**5-C** composite-key hash: key = (containerName, pathID); pathIDs are stable
per-build because they're metadata table indices — save data referencing
"item icon pathID 42" survives patching as long as assets aren't re-imported
with different ordering. Collisions handled by chaining in the map; the
*reason* they can't renumber: external saves.

**5-D** tk2d inventory: 100+ `tk2d*` assets (`tk2dMasking_*`, collections,
fonts). Migration: tk2dSpriteCollection → Unity SpriteAtlas; tk2dSprite →
SpriteRenderer; tk2d clipping → SpriteMask. Memo lives at
`analysis/tk2d_migration.md` (Phase 3).
